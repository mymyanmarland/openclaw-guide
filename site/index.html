OpenClaw ကို ၃ ဆင့်နဲ့ စတင်ပါ

လူတိုင်း ကြည့်ပြီး လုပ်လို့ရအောင် လုပ်ထားတဲ့ လမ်းညွှန်။ အဆင့်တွေ များများ မလိုဘူး။

1
Install လုပ်
curl -fsSL https://openclaw.ai/install.sh | bash
Windows: PowerShell မှာ iwr -useb https://openclaw.ai/install.ps1 | iex
2
Custom Base URL ထည့်
openclaw onboard --classic --install-daemon
Wizard မှာ Custom Provider ရွေးပြီး Base URL, key, model ထည့်ပါ။ (Custom Provider only appears with --classic.)
3
သုံးတော့
openclaw dashboard
Browser မှာ http://127.0.0.1:18789/ ပွင့်လာမယ်။

⚡ One-click Install

လက်နဲ့ တစ်ဆင့်ချင်း လုပ်စရာ မလိုဘူး။ script ကို run လိုက်ရင် install, Custom Base URL, backup, verify အကုန် လုပ်ပေးတယ်။

Linux / VPS:

git clone https://github.com/mymyanmarland/openclaw-guide.git cd openclaw-guide bash scripts/install.sh --base-url https://api.example.com/v1 --model your-model-id

Windows PowerShell:

git clone https://github.com/mymyanmarland/openclaw-guide.git cd openclaw-guide .\scripts\install.ps1 -BaseUrl https://api.example.com/v1 -Model your-model-id

First clone the repo — the script is inside it. Replace https://api.example.com/v1 and your-model-id with your real Base URL and model.

ဥပမာ — RelayModels + Claude (Linux):

git clone https://github.com/mymyanmarland/openclaw-guide.git cd openclaw-guide bash scripts/install.sh --base-url https://api.relaymodels.com/v1 --model claude-sonnet-5 --provider relaymodels

ဥပမာ — RelayModels + Claude (Windows):

git clone https://github.com/mymyanmarland/openclaw-guide.git cd openclaw-guide .\scripts\install.ps1 -BaseUrl https://api.relaymodels.com/v1 -Model claude-sonnet-5 -Provider relaymodels

API key ကို command ထဲမှာ မထည့်ပါနဲ့ — script က မေးလာတဲ့အခါ ရိုက်ထည့်ပါ။

Script က လုပ်ပေးတာ။ ① official installer နဲ့ OpenClaw တင်တယ်။ ② key ကို /models နဲ့ စစ်တယ်။ ③ config ကို backup ယူပြီးမှ provider ထည့်တယ်။ ④ Telegram token ပေးရင် channel ထည့်တယ်။ ⑤ Saves the API key to OpenClaw's auth store (gateway stopped), then starts the Gateway and waits until it is ready. ⑥ Probes the channels.
အရင် စမ်းချင်ရင် --dry-run (Linux) / -DryRun (Windows) နဲ့ စမ်းပါ။ ဘာမှ မပြောင်းဘူး။

VPS ပေါ် Install

Ubuntu / Debian VPS, Node 24.16+ သို့မဟုတ် 26.1+ လိုတယ်။ installer က လိုရင် Node ကို သူ့ဟာသူ ထည့်ပေးတယ်။

curl -fsSL https://openclaw.ai/install.sh | bash openclaw onboard --classic --install-daemon openclaw gateway status

--install-daemon က systemd user service အနေနဲ့ တင်ပေးတယ်။ reboot လုပ်လည်း ပြန် run တယ်။

Custom Base URL

OpenAI ပုံစံ provider မှာ base URL က /v1 နဲ့ ဆုံးရတယ်။ ဥပမာ https://api.relaymodels.com/v1။ Ollama မှာ http://127.0.0.1:11434 လို /v1 မပါတဲ့ လိပ်စာ သုံးရတယ်။

agents.defaults.model.primary = "myprovider/your-model-id"

401 = key မှားတယ်။ 404 = base URL မှားတယ်။

GUI — Control UI

Local မှာ openclaw dashboard လို့ run ရင် http://127.0.0.1:18789/ ပွင့်လာမယ်။ VPS ကို အဝေးကနေ သုံးချင်ရင် SSH tunnel, nginx + HTTPS + basic auth, ဒါမှမဟုတ် Tailscale ကို သုံးပါ။

ssh -L 18789:127.0.0.1:18789 user@your-server-ip

Telegram Bot

Telegram မှာ @BotFather ကို ဖွင့်ပါ။ /newbot လို့ ပို့ပြီး token ယူပါ။

openclaw channels add --channel telegram --token "YOUR_BOT_TOKEN" openclaw gateway restart openclaw channels status --probe openclaw pairing approve telegram <PAIRING-CODE>

Pairing code က ၁ နာရီ အတွင်း သက်တမ်းကုန်တယ်။ Token ကို ဘယ်သူနဲ့မှ မမျှပါနဲ့။

Windows

Hub: Native app, admin မလိုဘူး။ PowerShell: အောက်က command နဲ့ တင်ပါ။ WSL2: Linux နည်းအတိုင်း တင်ပါ။

iwr -useb https://openclaw.ai/install.ps1 | iex openclaw onboard --classic --install-daemon openclaw dashboard

Linux / VM

Linux desktop မှာ Linux install နည်းအတိုင်း တင်ပါ။ VM မှာ သီးသန့် version မလိုဘူး။ VM ထဲက OS အတိုင်း Windows နည်း ဒါမှမဟုတ် Linux နည်းကို သုံးပါ။ VM ပိတ်ရင် Gateway ရပ်တယ်။

Browser Control

Managed profile: OpenClaw က သူ့ဟာသူ ထိန်းတဲ့ Chromium ဖြစ်သည်။ ကိုယ့် personal browser နဲ့ မရောဘူး။ Extension relay: ကိုယ့် Chrome tab ကို attach လုပ်ပြီး ထိန်းတာဖြစ်သည်။ attach လုပ်ထားတဲ့ tab ကိုပဲ ထိန်းတယ်။

openclaw browser install openclaw browser --browser-profile openclaw start openclaw browser --browser-profile openclaw open https://example.com

Security

⚠️ port 18789 ကို public internet မှာ ဘယ်တော့မှ မဖွင့်ပါနဲ့။
  • ~/.openclaw/openclaw.json backup ရှိတယ်။ permission 600 ဖြစ်သည်။
  • API key, bot token ကို GitHub / chat / screenshot ထဲမှာ မတင်ထားဘူး။
  • Gateway မတက်ဘူး — openclaw gateway status, openclaw doctor စစ်ပါ။
