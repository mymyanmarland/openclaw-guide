OpenClaw — ၃ ဆင့်နဲ့ စတင်

အဆင့်တွေ များများ မလိုဘူး။ ဒီ ၃ ဆင့်ပဲ လုပ်ရင် ပြီးတယ်။

1

Install လုပ်

curl -fsSL https://openclaw.ai/install.sh | bash
Windows: PowerShell မှာ iwr -useb https://openclaw.ai/install.ps1 | iex
2

Custom Base URL ထည့်

openclaw onboard --classic --install-daemon
Wizard မှာ Custom Provider ရွေးပြီး Base URL, key, model ထည့်ပါ။ (Custom Provider only appears with --classic.)
3

သုံးတော့

openclaw dashboard
Browser မှာ http://127.0.0.1:18789/ ပွင့်လာမယ်။ Telegram လိုရင် openclaw channels add --channel telegram --token "YOUR_BOT_TOKEN"

လက်နဲ့ မလုပ်ချင်ရင် One-click script သုံးပါ။ အပြည့်အစုံ Guide မှာ One-click tab ကြည့်ပါ။

⚠️ port 18789 ကို public မဖွင့်ပါနဲ့။
