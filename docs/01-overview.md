# 01 — OpenClaw ဆိုတာ ဘာလဲ

OpenClaw ဆိုတာ open source, self-hosted AI agent ဖြစ်သည်။
ကိုယ့် စက်ပေါ်မှာ Gateway ဆိုတဲ့ service တစ်ခု run တယ်။
Gateway က port 18789 မှာ နားထောင်တယ်။

Gateway က ဒါတွေ လုပ်ပေးတယ်။
- Telegram, GUI, CLI ကနေ လာတဲ့ စာကို လက်ခံတယ်။
- ရွေးထားတဲ့ model ကို ခေါ်တယ်။
- file, shell, browser လို tool တွေကို သုံးခိုင်းတယ်။

ဒီ Guide က OpenClaw ကို အသစ်တင်မယ့်သူအတွက် ဖြစ်သည်။
